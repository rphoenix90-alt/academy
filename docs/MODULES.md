# 기능 모듈

기본 기능(로그인, 학원/직원, 학생, 클래스, 수납, 대시보드)은 항상 켜져 있습니다.

선택 모듈은 **Academy → 기능 모듈**에서 켜고 끌 수 있습니다(원장/관리자).

| 모듈 | 효과 |
|------|------|
| 종합 시간표 | 사이드바 Timetable |
| 강사 정산 | 사이드바 Settlement |
| 성적 관리 | 학생 상세 성적 탭 |
| 상담 이력 | 학생 상세 상담 탭 |
| 교재 관리 | 클래스 화면의 교재 탭 |
| 엑셀 일괄등록 | 학생 화면 엑셀 버튼 |
| 단체 문자 | 학생 화면 SMS 버튼 |

코드 위치: `src/registry.js`, `src/modules/`
