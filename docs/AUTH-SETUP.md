# 로그인(Auth) 설정

## Firebase Console에서 한 번만 (필수)

로그인/가입이 안 되면 **가장 먼저** 이것을 확인하세요.

1. [Authentication → Sign-in method](https://console.firebase.google.com/project/linkworks-hak/authentication/providers) 열기  
2. **Email/Password** 클릭  
3. **사용 설정** 켜기 → **저장**

## 추천 로그인 구조

| 구분 | 방법 |
|------|------|
| **최초 관리자** (학원당 1회) | 이메일 + 비밀번호(6자 이상) |
| **직원** (원장·관리자·강사) | 전화번호 + 숫자 4자리 |

직원 계정은 최초 관리자가 Academy에서 등록한 뒤, 직원이 전화로 로그인합니다.

## 최초 관리자 계정 만들기

1. https://linkworks-hak.web.app 접속  
2. **최초 관리자 계정 만들기** 화면이 열립니다 (아직 관리자가 없을 때)  
3. **이름 / 이메일 / 비밀번호(6자 이상)** 입력 → 생성  

같은 이메일로 Auth만 만들어지고 중간에 실패한 경우, 같은 정보로 다시 「계정 만들기」를 누르면 프로필이 자동 복구됩니다.  
이미 만든 뒤에는 **최고 관리자 로그인**을 사용하세요.

## 직원 로그인

1. Academy → 직원 등록 (**전화번호** 필수, 권한: 원장/관리자/강사)  
2. 직원이 **전화번호 + 뒤 4자리**로 최초 로그인  
3. 새 비밀번호(4자리) 설정 후 이후 그 PIN으로 로그인  

> 최고 관리자(이메일) 직원 카드에는 전화 로그인을 연결하지 마세요.

## 보안

- 비밀번호는 Firebase Auth에만 저장됩니다.
- Firestore는 학원 멤버만 접근합니다.
- Firestore Rules는 Hosting 배포 시 함께 배포됩니다 (`deploy.yml`).
